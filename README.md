# 髮源頭皮護理中心 官方網站

頭皮護理中心的單頁式（One Page）官方網站，介紹生髮、護髮與諮詢三大核心服務。

## 技術

純 HTML / CSS / JavaScript，無需建置工具，可直接部署至任何靜態主機（GitHub Pages、Netlify、Vercel 等）。

## 結構

```
index.html      主頁面（首頁、療程介紹、諮詢流程、關於我們、線上預約、聯絡資訊）
css/style.css   樣式
js/main.js      互動行為（行動選單、預約表單前端驗證）
```

## 本地預覽

```bash
python3 -m http.server 8000
```

再開啟 http://localhost:8000
